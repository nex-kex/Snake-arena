# Управление

## Принцип
Змейка едет сама. Игрок только **меняет курс**. Срочные повороты — клавиши/мышь/тач,
несрочные действия — текстовая консоль на естественном языке.

## Единый канал: фразы-команды
Любой ввод превращается в сообщение `{"type":"command","text":"<фраза>"}`.
Так сервер имеет один парсер для людей, клавиатуры и бота.

### Клавиатура и тач → фраза

| Ввод | Фраза |
|---|---|
| `↑` / `W` | `go up` |
| `↓` / `S` | `go down` |
| `←` / `A` | `go left` |
| `→` / `D` | `go right` |
| `Q` | `turn left` |
| `E` | `turn right` |
| свайп | `go <направление свайпа>` |
| `Enter` после смерти | `respawn` — новый запрос на вход в раунд |

### Мышь / касание-удержание
Клиент считает направление от головы к курсору, выбирает ближайшее допустимое
из 3 и отправляет фразу только **при смене** направления (не чаще 1 раза за тик).
Это ограничение отправки действует на стороне клиента только для мыши
и касания-удержания.

### Текстовая консоль (свободный ввод)

| Фраза | Результат |
|---|---|
| `иди вверх/вниз/влево/вправо`, `go up…` | задать направление |
| `поверни налево/направо`, `turn left/right` | относительный поворот |
| `покажи счёт`, `score` | `scores` — таблица счёта |
| `кто играет`, `players` | `players` — список игроков |
| `возродиться`, `respawn` | вернуться в игру |
| `help`, `помощь` | список команд |

Неизвестная фраза → сообщение `error` с кодом `unknown_command`, состояние не меняется.

## Клиентская плавность
- Клиент не ждёт ответа сервера для отрисовки поворота головы (необязательная оптимистичная подсказка).
- Между тиками позиции интерполируются, чтобы движение выглядело плавным.

## Очередь поворотов
Сервер принимает несколько команд между тиками и хранит до 2 направлений
в порядке приёма. Перед движением выполняется не более одного поворота за тик.
При заполненной очереди новая команда молча отбрасывается; принятые команды
не заменяются.

Проверка повторов и разворота на 180°, а также вычисление относительного поворота
выполняются относительно последнего направления в очереди. Если очередь пуста,
используется текущий курс. Повторы и развороты молча игнорируются.

Клавиатура, свайпы, текстовые команды и бот могут поставить два быстрых поворота
в очередь без ограничения «одна отправка за тик». Ограничение для мыши
и касания-удержания описано выше. Подробности и пример — в `game-rules.md`.

## Вход в раунд и перерыв
- Кнопка «Войти в раунд», `Enter` после смерти и команда `respawn` запускают
  повторный вход с теми же проверками, что для `join`. Кулдаун возникает после отказа.
- После отказа игрок остаётся на странице подключения; кнопка недоступна
  в течение 5 секунд от отказа. Ранние запросы срок не продлевают.
  Имя — 1–16 букв `A–Z` и `a–z`, уникальное с учётом регистра.
- При нехватке места показывается ожидание спавна. Когда истекли 5 секунд,
  соединение закрывается; можно сразу переподключиться и войти заново.
  Конец раунда отменяет запрос; для следующего нужно подтвердить участие.
- В пятисекундном перерыве показывается рейтинг прошлого раунда.
  Живые игроки автоматически ожидают следующий раунд; мёртвые входят заново.
  Неподтвердившие мёртвые игроки отключаются в конце перерыва. Повороты
  во время перерыва не принимаются; при старте очередь очищается, направление
  вычисляется от шеи к голове.
- Кнопка «Выйти из раунда» закрывает соединение и удаляет участие.
  Переподключение — новый игрок без счёта, змейки и прежнего кулдауна.
