# Правила игры

Статус: **черновик для согласования** (неделя 1).

## Поле и время
- Поле 40×30 клеток, координаты `(x, y)`, `(0,0)` — левый верхний угол, `y` растёт вниз.
- Тик каждые 150 мс (параметр `tick-ms` в `server/src/snake_arena/config.clj`).
- Змейка **всегда движется**: каждый тик голова смещается на клетку по текущему направлению.

## Поворот
- Допустимы 3 направления из 4: **назад (на 180°) запрещён** и молча игнорируется.
- За тик применяется один поворот из очереди игрока.
- Очередь поворотов — максимум 2 элемента; лишние отбрасываются.
- Поворот, совпадающий с текущим курсом, не добавляется в очередь.
- Проверка «назад» делается относительно **последнего поставленного в очередь** направления.

## Еда
- На поле поддерживается минимум N единиц еды (`min-food`).
- Съел еду: рост на 1 (хвост на этом тике не убирается), счёт +1.
- Умершая змейка превращается в еду на своих клетках.

## Столкновения (порядок проверки в тике)
1. Все головы сдвигаются одновременно.
2. Выход за границу поля → смерть.
3. Голова в клетке чужого/своего тела (кроме хвоста, который освобождается в этом тике) → смерть.
4. Две головы в одной клетке, либо обмен клетками → **обе** погибают.
5. Змейка в период неуязвимости (3 тика после спавна) не умирает от столкновений с телами, но стены убивают.

## Смерть и возрождение
- Мёртвая змейка исчезает, клетки → еда.
- Возрождение: кнопка / `Enter` / команда `возродиться` / `respawn`.
- Спавн в свободной области минимум 5×5, длина 3, направление — от ближайшей стены.
- Счёт при возрождении сбрасывается, лучший результат сохраняется в таблице.
