# Защита проекта

## Сценарий демо
1. Запускаем сервер, два окна клиента, бота.
2. Два игрока управляют стрелками/WASD — видно живое движение на общем поле.
3. Бот сам ищет еду; в логе виден его выбор (`reason` из A*).
4. Змейка врезается: гибнет, превращается в еду; бот подаёт новый запрос на вход с учётом кулдауна и ожидания спавна.
5. Дожидаемся окончания раунда: рейтинг виден 5 секунд; живые змейки остаются
   на месте, затем обнуляется счёт и заново появляется еда.
6. Проверяем отказ восьмому участнику, кулдаун входа и отсутствие восстановления
   участия после переподключения.
7. Вводим неверную фразу в консоль → `error`, состояние не ломается.
